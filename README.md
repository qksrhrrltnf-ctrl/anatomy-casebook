# 공학 해부도 사례집

실제 기계와 장치의 속을 아이소메트릭 해부도로 보여 주는 인터랙티브 한국어 수업 자료입니다.

- 값을 바꾸면 그림이 물리 모델대로 반응합니다.
- 부품에 마우스를 올리면 한국어 설명이 나옵니다.
- 단계 가이드와 탐구 질문으로 원리를 따라갈 수 있습니다.

**바로 보기**: https://qksrhrrltnf-ctrl.github.io/anatomy-casebook/

## 들어 있는 자료

**기술교육 공학 사례**(인쇄용 A4 PDF 포함)
- 서보 모터
- 내진·면진 고층 건물
- 히트펌프
- 풍력 발전기
- 광섬유 통신

**과학·기술 원리 해부도**
- 누름 버튼 회로
- 다이얼 게이지
- 데스크 컴퓨터
- 오락기 단면
- 로켓 엔진
- 물결통
- 다이얼 자물쇠
- 버튼 시험대
- 반점판 유리 방울

## 사용 방법

- 위 주소에서 그림을 누르면 브라우저에서 바로 열립니다.
- 각 페이지는 파일 하나(`사례집/<이름>/<이름>-ko.html`)입니다. 저장소를 내려받으면(Code → Download ZIP) 인터넷 없이 교실에서 쓸 수 있습니다.
- 화면은 두 가지입니다. `-ko.html`은 어두운 화면, `-ko-light.html`은 밝은 화면입니다.
