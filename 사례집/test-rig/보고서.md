# test-rig 보고서

기준: `wheresryan22/anatomy` 커밋 `1482e84`, 예제 폴더 `examples/test-rig/` (React, Fig 6 "Press and pull")

## 1. 재현 결과

- **판정 방식**: 원본 HTML 없음, 렌더 확인과 콘솔 오류로 판정합니다. 이 예제는 Next.js용 React 컴포넌트만 들어 있고 `build.mjs`도 원본 HTML도 없어서 바이트 비교를 할 수 없습니다.
- **렌더**: 다크·라이트 모두 정상으로 나옵니다. 받침판, 4개 스프링이 걸린 캐리지와 가이드 로드 2개, 유리 버튼, 뒤쪽 레일과 손가락 프로브, 다이얼 게이지, 명판, 범례와 캡션이 모두 보입니다.
- **콘솔 오류**: 없습니다. `capture.mjs`는 console error와 warning, 잡히지 않은 예외를 모두 기록하는데, 모든 캡처(정적 빌드 http, file://, Vite 개발 서버)에서 `console: clean`이었습니다. React 개발 모드(StrictMode 포함)에서도 key 경고 같은 경고가 나오지 않았습니다.
- **가로 스크롤**: 1440px, 390px 모두 없습니다.
- **움직임**: 자동 투어가 누르고(크기 120.0 × 32.0 → 약 129.7 × 34.5), 80px 당기고(135.5 × 33.8 · lean 10.6 px), 놓아서 원위치로 돌아오는 순서가 시간대별 판독값으로 확인됩니다. 캡션의 "Pulled 80 px it leans 10.6 px"와 판독값이 일치합니다.
- **reduced motion**: `prefers-reduced-motion: reduce`에서는 투어가 돌지 않고 3초 뒤에도 `120.0 × 32.0 · lean 0.0 px` 휴지 자세로 남습니다.

### 하네스 구성 (`C:\anatomy-work\react-harness`)

- Vite 8.3.5 + `@vitejs/plugin-react` 6.2.1 + React 19.3.0 / react-dom 19.3.0 + TypeScript 5.9.3 (+ esbuild 0.28.2, `@types/react`·`@types/react-dom` 19.3.0). 버전은 저장소 CI 기준에 맞췄습니다.
- `kit/` 전체와 `examples/test-rig/`, `examples/spot-plate/`를 `src/kit`, `src/examples/...`로 **복사**했습니다. 상대 경로(`../../kit/...`)가 그대로 맞도록 폴더 구조를 유지했으므로 import 별칭은 쓰지 않았습니다. 복사본은 `diff -r`로 원본과 같음을 확인했습니다.
- 하네스 쪽에만 둔 코드:
  - `index.html`: `<body class="iso" data-theme="dark|light"><main class="iso-page" id="root">`. SVG 예제들의 `pageHtml()` 껍데기와 같은 구조입니다.
  - `src/harness/page.css`: `kit/iso-kit.ts`의 `PAGE_CSS`(폭 650px)를 옮겨 적었습니다.
  - `src/harness/mount.tsx`: `kit/iso.css`와 `page.css`를 import하고, `createRoot`로 `<React.StrictMode>` 안에 그림을 렌더링합니다. `?theme=light|dark` 쿼리로 테마를 바꿀 수도 있습니다.
  - `src/harness/test-rig.tsx`: `<TestRigFigure />`를 마운트합니다.
  - `vite.config.ts`: 환경변수(`HARNESS_FIG`, `HARNESS_THEME`)로 그림과 테마를 고르고, `vite-plugin-singlefile` 2.3.4로 JS·CSS를 인라인합니다. `resolve.extensions`를 `.tsx, .ts`가 먼저 오도록 바꿨습니다. `kit/`에 `iso-kit.ts`와 `iso-kit.mjs`가 함께 있는데, Vite 기본 순서는 `.mjs`가 먼저라서 React 키트가 기준으로 삼는 `iso-kit.ts`를 고르게 하려는 것입니다.
  - `build-all.mjs`: 4번(그림 2 × 테마 2) 빌드해 `dist/<이름>.html`, `dist/<이름>-light.html`을 만듭니다.
- Next.js 전용 구분(`"use client"`, 서버 컴포넌트인 `art.tsx`)은 그대로 두고 전부 클라이언트에서 렌더링했습니다. Vite는 `"use client"` 지시문을 문자열 문장으로 보고 무시합니다.
- `tsc --noEmit`(strict) 통과했습니다.

## 2. 무엇을 설명하는 그림인가

UI의 "누르면 살짝 부풀고, 누른 채 끌면 고무줄처럼 버티며 기울어지는 유리 버튼" 동작을 실물 시험대로 바꿔 보여 줍니다. 120 × 32 크기의 유리 버튼이 두 개의 가이드 로드 위 캐리지에 얹혀 있고, 캐리지는 스프링 네 개로 붙잡혀 있습니다. 뒤쪽 레일 위를 달리는 손가락 프로브가 버튼을 누르고 옆으로 당기며, 오른쪽 다이얼 게이지가 기울어진 양(lean)을 읽습니다. 판독값은 현재 크기와 lean(px)입니다.

수식 쪽으로는 `rig.ts`에 감쇠 스프링(강성·감쇠 계수, 감쇠비 `zeta`)과 고무줄 저항 함수(`rubberBand`: 당길수록 덜 따라감)가 들어 있고, 그림은 이 모델을 그대로 움직입니다.

## 3. 조작법

- **마우스/터치**: 그림 위에서 움직이면 프로브가 따라옵니다. 누르면 버튼을 누르고, 누른 채 좌우로 끌면 당깁니다. 떼면 스프링이 되돌립니다.
- **키보드**: 그림에 포커스를 두고 Space 또는 Enter로 누르기/놓기, ←→(↑↓)로 손가락 이동(Shift는 3배), Home/End로 끝까지, Esc로 놓기.
- **자동 투어**: 화면에 보이고 아무 조작이 없으면 1.4초 뒤부터 7.6초 주기로 누름→80px 당김→놓음을 반복합니다. 조작이 끝나고 3.6초 뒤 투어가 다시 시작합니다. reduced motion에서는 투어가 돌지 않습니다.

## 4. 눈여겨볼 기법

- **React 구조(2단계에서 React로 만들 때의 본보기)**: `view.ts`(투영 `P`, 치수) → `geometry.ts`(정적 경로를 모듈 로드 때 한 번 계산) → `pose.ts`(움직이는 부품의 경로를 자세마다 계산) → `art.tsx`(정적 부품 JSX) → `live.tsx`(`"use client"`, ref로 DOM 직접 갱신, 재렌더링 없이 판독값 갱신) → `figure.tsx`(`Plate`). `references/react.md`가 이 예제를 기준 배치로 소개합니다.
- **키트 함수**: `extrude`, `slabOf`, `insetPlan`, `onTop`, `planOutline`, `circleRing`, `topMatrix`(윗면 글자) 등 `iso-kit.ts`의 평면→입체 함수로 모든 부품을 만듭니다. lathe, tube, WebGL, 3D, 분해, 인쇄는 쓰지 않습니다.
- **물리 모델과 그림 분리**: `rig.ts`는 DOM 없는 순수 모델(스프링 적분, 고무줄 저항)이고, 캡션 숫자(`readoutOf(PULLED)`)도 같은 모델에서 계산합니다. 설명 문구와 그림이 어긋나지 않게 하는 방법으로 참고할 만합니다.
- **접근성**: `role="slider"`, `aria-valuenow`/`aria-valuetext`를 루프 안에서 갱신하고, reduced motion을 존중합니다.

## 5. 교육 활용 메모

- 중학교 과학 "힘과 운동"(탄성력, 용수철)과 고등학교 물리학 "역학"(훅의 법칙, 감쇠 진동)에서, 누르고 놓았을 때 스프링이 진동하며 제자리로 돌아오는 모습을 판독값과 함께 보여 줄 수 있습니다.
- 기술·가정의 "기술 시스템"이나 정보 교과의 사용자 인터페이스 단원에서, 화면 버튼의 반응(누름·끌기)을 측정 장치로 바꿔 설명하는 사례로 쓸 수 있습니다. 다이얼 게이지 읽기는 측정 단원 보조 자료로도 쓸 수 있습니다.

## 6. 문제와 미해결 사항

- 원본 HTML이 없어 바이트 비교는 하지 않았습니다. 원저자의 실서비스(Next.js) 화면과 픽셀 대조도 하지 않았습니다.
- 하네스는 전부 클라이언트 렌더링이라 `references/react.md`가 말하는 "큰 페이지의 서버 스트리밍 key 경고 함정"은 이 환경에서 재현되지 않습니다. 확인한 것은 클라이언트 렌더링에서 경고가 없다는 사실까지입니다.
- 390px 폭에서는 카드 아래쪽 힌트("PRESS, THEN PULL")와 판독값이 한 줄에 들어가지 않아 두 줄로 나뉩니다. 겹치거나 잘리지는 않습니다.
- Windows에서 캡처했으므로 글꼴은 `iso.css` 글꼴 목록 가운데 Windows에 있는 글꼴로 표시됩니다.
- 직접 본 캡처(데스크톱 다크·라이트, 투어 순간, 호버, 390px, reduced, 확대)에서 부품이 빠지거나 앞뒤 겹침이 틀린 곳은 찾지 못했습니다. 스프링은 캐리지 프레임 막대 뒤로 올바르게 가려지고, 투어가 왼쪽으로 당길 때 캐리지가 왼쪽으로 밀려 왼쪽 스프링은 줄어들고 오른쪽 스프링은 늘어나며, 다이얼 바늘이 돌아갑니다.
