## 1. 무엇을 만들었는가

React 예제 "누르고 당기기"(Fig 6)에 공통 교육 레이어(edu-kit)를 붙인 한국어 교육판입니다. 버튼을 놓은 뒤 되돌아오는 운동을 감쇠 진동으로 보여 줍니다.

| 기능 | 내용 |
|---|---|
| 한국어 카드 | 제목·힌트·판독값(`크기 … · 기울기 … px`)·범례·캡션을 한국어로 바꿨습니다. 캡션 숫자는 `{키}` 템플릿이라 변수를 바꾸면 따라 바뀝니다. |
| 변수 패널 | 강성 k(80~800), 감쇠비 ζ(0.1~2.0), 당김 거리(10~100 px), "세 가지 감쇠 겹쳐 보기" 토글, "당겼다 놓기" 실행 버튼. 바꾸면 그림의 되돌림 스프링이 바로 바뀝니다. |
| 공식 7줄 | 감쇠비 ζ = c ÷ (2√k), ω₀ = √k, 주기 T, 훅의 법칙 F = −k·x, 고무줄 저항 x₀, 첫 되튐, 멈출 때까지 걸리는 시간. 모두 그림과 같은 모델(`rig.ts`)에서 계산합니다. |
| 다이얼 게이지 기록(그림 밖 그래프) | 놓은 뒤 기울기-시간 곡선. 지금 설정, 지난번 놓기(점선), ζ 0.20/1.00/2.00 겹쳐 보기, 지금 바늘 위치를 따라가는 점, 십자선 판독, 표 보기. |
| 직접 조작 | 그림을 누르고 좌우로 끌기, Space/Enter로 누르기·놓기, 화살표로 당기기, Esc로 놓기. 마우스를 올리기만 하면 툴팁만 뜨고 프로브는 움직이지 않습니다(kit 표준 정책). |
| 부품 툴팁·목록 | 21개 부품. 용수철과 바늘은 가는 선이라 투명한 넓은 hit 선(`data-edu-hit`)을 같이 두었습니다. |
| 단계 가이드 | 8단계: 둘러보기 → 누르기 → 훅의 법칙 → 고무줄 저항 → 감쇠 진동 → 저감쇠 → 임계·과감쇠 → 강성 k의 역할. |
| 탐구 질문 | 4개: ζ 0.2→1.0 첫 되튐, k 4배일 때 주기(절반), 가장 빨리 멈추는 ζ(1.0), 당김 4배일 때 기울기(1.72배). |

## 4. 남은 문제

- **선 끝 검사 11개.** 교육판에서 11 / 458개의 끝이 떠 있습니다. 1단계 원본(`test-rig.html`)도 같은 11개입니다. 레일 기둥 선, 명판 줄 같은 원본 그림의 장식선이며 교육판이 새로 만든 것은 없습니다. React 예제는 원본에 감사·선 끝 기준이 없었으므로 그림 기하는 고치지 않았습니다. 0으로 맞출지는 결정이 필요합니다.
- 질문 확인 장면에서 해설은 `to` 자세를 적용한 순간(3초 뒤)에 뜨고, 그림의 놓기 동작은 그 뒤 약 1.3초에 일어납니다. 해설 숫자는 모델 값이라 맞지만 그림이 조금 늦게 따라옵니다.
- 같은 설정으로 다시 놓으면 "지난번" 점선이 생기지 않습니다(설정이 바뀌었을 때만 남깁니다).
- 질량은 모델처럼 1로 고정했습니다. k의 단위는 "질량 1 모델 단위"로만 밝혔습니다.
