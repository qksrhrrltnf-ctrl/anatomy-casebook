## 2. 무엇을 설명하는 그림인가

1981년풍 업라이트 오락기(높이 178 cm)의 왼쪽 옆판을 떼어 낸 단면입니다. 부품은 고체 약 240개(감사 기준 243개)와 케이블 15개입니다. 주제는 "동전 하나가 어떻게 게임을 시작시키는가"이고, 인쇄본의 표어는 "One wire, one pulse, one credit"입니다.

캡션과 `sheet.mjs`에 적힌 흐름은 다음과 같습니다.

1. 25센트 동전(지름 24.26 mm)을 왼쪽 슬롯에 넣으면 코인 메커가 동전을 검사합니다.
2. 동전은 30° 경사로를 굴러 내려가며 가는 코인 스위치 와이어를 밀어 젖힙니다. 이것이 펄스 하나, 즉 동전 하나입니다.
3. 동전은 경사로 끝에서 떨어져 27 cm 아래의 열린 금고(cash box)에 들어갑니다. 코인 미터의 숫자가 1 오릅니다.
4. 같은 펄스가 전원 릴레이를 래치합니다. 그래서 첫 동전이 기계를 깨웁니다. 마키 형광등이 켜지고, CRT 히터가 약 2초 동안 예열되고, 보드가 RAM·ROM 자체 시험을 합니다.
5. 이어서 어트랙트 모드(데모 화면)가 기울어진 모니터 평면 위에 그려집니다. 모니터는 세로형 게임용으로 옆으로 눕혀 달려 있습니다. 해상도는 224 × 288, 수평 주사 주파수는 15.734 kHz이며, 주사선이 화면 위아래 방향으로 지나갑니다. 전원을 끄면 그림이 세로선 하나로 접힙니다.
6. 조이스틱을 기울이면 패널 아래의 마이크로스위치가 닫힙니다.

`live.js`의 물리값은 다음과 같습니다.

- 경사로 가속도는 `ROLL_A = (2/3)·g·sin30°`입니다. 굴러가는 원판의 가속도 공식입니다.
- 경사로를 떠난 뒤의 낙하는 같은 중력값(`GRAV = 1962` 월드 단위/s²)으로 계산합니다(`T_DROP`, `LAND_Y`).
- 펄스는 케이블을 따라 덩어리(chunk)별로 차례로 밝아지며 보드까지 전달됩니다(`pulse`, `data-hot`).

## 3. 조작법

카드 아래 안내문은 "C or click the quarters · ← → · space"입니다. 근거는 `live.js`의 이벤트 처리기입니다.

| 입력 | 동작 |
|---|---|
| `C` 또는 `5` 키, 받침판 위 동전 더미나 코인 도어 클릭 | 동전 투입. 동전이 더미에서 슬롯으로 날아갑니다. 동전 더미와 도어 위에서는 커서가 손가락 모양으로 바뀝니다. |
| `←` / `→` | 조이스틱을 기울입니다. 키를 떼면 돌아옵니다. 어트랙트 모드에서는 우주선이 움직이고, 읽음값 끝에 `stick ←/→`가 붙습니다. |
| `Space` / `Enter` | 발사 버튼을 누릅니다. |
| `Esc` | 전원을 끕니다. 그림이 선으로 접히고 크레딧이 0이 됩니다. |
| 자동 투어 | 아무것도 하지 않으면 다음 순서로 반복합니다. 1.4초 동전 투입, 9.5~13.3초 스틱 좌우와 발사, 15.2초 두 번째 동전, 24초 전원 끄기, 27.5초 처음부터 다시. 사용자가 입력하면 멈추고, 12초 동안 입력이 없으면 다시 시작합니다. |
| 움직임 줄이기(reduced motion) | 투어가 돌지 않습니다. 동전을 넣으면 곧바로 결과 상태(금고 착지, 전원 켜짐)로 넘어갑니다. |

오른쪽 아래 읽음값은 `coin · 24.26 mm quarter` → `coin · into the slot` → `mech · checking the coin` → `coin · rolling down the chute` → `coin switch · meter 004128` → `warming · heater …` → `self-test · RAM OK · ROM OK` → `credit 1 · 15.734 kHz` 순서로 바뀝니다. 캡처할 때 실제로 이 순서를 확인했습니다.

마우스를 올려도 그림 자체는 바뀌지 않습니다. CSS에서 정의한 것은 커서 변경뿐입니다.

## 4. 눈여겨볼 기법

- **lathe (`kit/lathe.mjs`)**: 둥근 부품(CRT 목, 조이스틱 공, 버튼, 노브, 동전)을 만드는 데 씁니다. 페이지 안에도 같은 모듈을 넣어 움직이는 부품을 다시 그립니다.
- **tube (`kit/tube.mjs`)**: 케이블과 하네스 15가닥을 그립니다. 코인 와이어, 비디오 케이블, 전원 케이블, 룸(loom)이 여기에 해당합니다. 펄스가 케이블 조각을 따라 흐르는 연출이 이 구조 위에서 동작합니다.
- **감사 (`kit/audit.mjs`)**: 빌드 끝에서 `A.auditOrExit`로 관통, 단자, 지지, 깊이 순서를 증명합니다. 단면 그림에서 케이블이 판을 뚫고 지나가지 않음을 자동으로 보장하는 예입니다.
- **README가 이 예제의 요점으로 꼽은 것**:
  - 단면 속 메커니즘이 보이도록 카메라를 놓는 방법(방위각 146°, 고도 24°)
  - 오목한 보드를 임의 축의 각기둥(prism)으로 그리는 방법
  - 움직이는 부품을 빌드와 같은 모듈(`parts.mjs`)로 페이지에서 다시 그리는 방법
  - 정해진 그리기 순서 안에 예약 슬롯을 두어 살아 있는 동전과 와이어를 그리는 방법
- **평면 위 화면**: CRT 화면(`screen.mjs`)과 코인 미터 숫자를 기울어진 면의 평면 행렬(`planeMatrix`)로 그립니다. 자체 시험, 격자, 어트랙트 모드 그림이 유리 평면에 붙어 보입니다.
- **인쇄**: `sheet.mjs` 하나로 포스터, 도면, 상세본 PDF를 만듭니다. 카드 오른쪽 위의 PDF 버튼이 같은 폴더의 `arcade-cabinet-poster-a4.pdf`를 엽니다.
- **쓰지 않은 기법**: WebGL, 3D, 분해는 쓰지 않았습니다.
- **2단계 참고점**: "작은 사건 하나(동전) → 신호 전달(케이블 펄스) → 시스템 상태 변화(전원, 화면)"를 실물 인과 사슬로 보여 주는 구성은 센서-제어 회로나 자동화 장치 주제에 그대로 옮길 수 있습니다. 물리값(구름 가속도, 낙하)을 코드 상수로 두고 움직임과 읽음값을 같은 모델에서 뽑는 방식도 참고할 만합니다.

## 5. 교육 활용 메모

- **중학교 과학 '운동과 에너지'·고등학교 물리학 '역학'**: 30° 경사면을 구르는 동전(가속도 2/3·g·sinθ, 미끄러짐과 구름의 차이)과 경사로 끝에서 떨어지는 포물선 낙하를 실물 장면으로 보여 줄 수 있습니다.
- **기술·가정 '전기·전자 기술', 고등학교 정보·공학 일반**: 스위치 → 펄스 → 계수기(미터) → 릴레이 래치 → 전원 공급으로 이어지는 스위치·릴레이 회로와 신호 전달을 설명할 수 있습니다. CRT 주사(15.734 kHz)와 세로로 눕힌 화면은 디스플레이 원리 수업의 보조 자료로 쓸 수 있습니다.

## 6. 문제와 미해결 사항

- **재현 차이**: 없습니다. HTML은 다크와 라이트 모두 바이트가 일치하고, 감사와 선 끝 검사도 통과했습니다.
- **동전이 경사로에서 잘 보이지 않습니다**: 경사로 구간의 동전은 화면에서 약 7 px 크기이고, 오른쪽 옆판 앞 모서리에 상당 부분 가려 작은 호로만 보입니다(`shots/*-coin-rolling-zoom.png`). 슬롯 투입 순간과 금고로 떨어지는 순간은 잘 보입니다(`shots/*-coin-falling-zoom.png`). 원본 설계가 그런 것이며 수정하지 않았습니다.
- **헤드리스에서 타이밍이 늘어집니다**: 다크 투어 캡처에서 페이지 시간이 실제 시간보다 늦게 흘렀습니다. +10초에도 아직 자체 시험 중이었습니다. 라이트 캡처에서는 +6초에 어트랙트 모드에 들어갔습니다. 다른 에이전트의 Chrome과 동시에 실행되어 프레임이 떨어졌기 때문으로 추정합니다. 프레임당 시간 간격이 1/30초로 묶여 있기 때문입니다(`live.js`의 `dt` 상한). 그림의 결함은 아닙니다.
- **포커스 테두리**: 키로 조작한 drive 캡처(`*-coin-rolling.png`, `*-attract-stick.png` 등)에는 카드 안쪽에 포커스 테두리가 보입니다. `:focus-visible` 스타일에 따른 정상 동작입니다.
- **상세본 PDF 확대 원 A(Coin mech)**: 미리보기 해상도에서는 원 안의 메커 모양이 뚜렷하지 않습니다. 원본 PDF를 렌더링해 비교하지는 못했습니다.
- **미실행**: `drive.mjs`의 `["lines"]` 동작으로 움직이는 자세(스틱 기울임 등)를 검사하는 일은 하지 않았습니다. 정지 상태만 검사했습니다.
