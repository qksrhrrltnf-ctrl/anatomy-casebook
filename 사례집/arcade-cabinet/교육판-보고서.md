## 2. 넣은 것

**한국어 카드.** 모서리 글자, 범례, 캡션, 판독값, 화면 낭독기용 상태 문구를 한국어로 바꾸었습니다. 화면 속 픽셀 글자(`INSERT COIN`, `RAM OK` 등)와 미터 숫자는 그림 안의 라벨이라 그대로 두었습니다.
- 판독값 예: `동전 · 지름 24.26 mm 25센트` → `메커 · 동전을 검사합니다` → `구름 · 0.20 s · 0.65 m/s`(경사로를 내려가는 동안의 모델 시간과 속력) → `낙하 · 0.12 s` → `착지 · 수평 17.16 cm` → `예열 · 히터 0.8 s` → `자체 시험 · RAM 정상 · ROM 정상` → `크레딧 1 · 15.734 kHz · 스틱 →`
- 캡션의 숫자는 모두 템플릿이라 모델을 따릅니다. 중력을 바꾸면 캡션의 경사로 시간도 바뀝니다.

**변수 패널(실험 탭).** 그림이 실제로 반응하는 것만 두었습니다.
- 동전 넣기, 스위치 와이어 튕기기, 전원 끄기(1회 실행 버튼)
- 동전의 운동: 구름 / 미끄러짐(마찰 없음). 다음 동전부터 가속도, 시간, 착지점이 바뀝니다. 미끄러지면 동전 무늬가 돌지 않습니다.
- 중력 가속도 g: ¼ g · ½ g · g · 2 g. 숫자(2.45~19.62 m/s²)는 모델의 `GRAV`에서 빌드가 계산해 넣었습니다.
- 시간 배율: 1배 · ½배 · ¼배 · ⅒배. 원본의 실제 시간 타이머(`setTimeout`)를 모델 시간 예약으로 바꾸어, 느리게 해도 순서(스위치 → 전원 → 크레딧)가 어긋나지 않습니다.
- 다중 섬광 궤적: 메커를 나온 뒤 0.05초마다 동전 위치를 남깁니다. 경사로에서는 간격이 1 : 3 : 5 : 7…로 늘고, 낙하에서는 포물선이 보입니다. 직전 동전의 궤적은 흐리게 남겨 비교할 수 있습니다.
- 경사로 확대: viewBox를 경사로·스위치·금고·미터 영역으로 바꿉니다. 1단계에서 지적된 "경사로 위 동전이 7 px라 안 보임" 문제를 해결합니다.
- 신호 흐름 보기: 펄스를 ①~⑧ 차례로 늘어놓고(스위치 → 미터 배선 → 코인 신호선 → 릴레이 → 주전원 → 직류 전원 → 비디오 케이블 → 고압선·넥 케이블), 해당 부품을 차례로 강조하며 상태 줄에 설명합니다. 원본에 없던 주전원·고압선·넥 케이블·스틱 배선 펄스를 추가했습니다(케이블 경로는 원본 그대로).
- 조이스틱: ← · 가운데 · → · 화면 쪽 · 몸 쪽(휴대폰용). 원본은 좌우만 썼는데 앞뒤 축도 살렸습니다.
- 경사각 θ(계산만): 10~60도. 그림의 경사로는 다시 빌드해야 바뀌므로 공식 블록에만 반영합니다.
- 공식 블록: 가속도 `a = g·sinθ ÷ (1 + β)`, 시간 `t = √(2L ÷ a)`, **측정 시간(스톱워치)**, 끝 속력, 낙하 시간(정지 낙하와 비교), 착지점(금고 안쪽 거리와 비교), 구름 조건 `μ ≥ tanθ ÷ 3`, 다른 경사각 계산. 아래 문장에 β = I ÷ (mR²), 원판 I = ½·m·R²이므로 질량 m과 반지름 R이 지워진다는 것을 기호로 적었습니다(동전 질량 같은 소스 밖 수치는 쓰지 않았습니다).
- 미끄러짐을 고르면 상태 줄이 노란 경고로 "수평 19.82 cm를 날아가려 하지만 금고 안쪽은 18.68 cm뿐이라 뒤 벽에 부딪힌다"고 알립니다.

**직접 조작.**
- 동전 넣기: C 키, 동전 더미·코인 도어 클릭(원본), 패널 버튼
- 조이스틱: 공을 끌어서 2축으로 기울이기(새로 추가). 공과 액추에이터가 받침점을 사이에 두고 반대로 움직여 그쪽 마이크로스위치가 닫히고, 스틱 배선 → 하네스로 펄스가 갑니다. 화살표 키 4방향도 됩니다.
- 코인 스위치 와이어 튕기기: 스위치·와이어 클릭이나 F 키(새로 추가). 와이어가 감쇠 진동하며 돌아오고 펄스 1개로 미터·크레딧이 오릅니다. 가는 와이어에는 투명한 넓은 클릭 영역을 덧댔습니다(`iso-line` 아님).
- 발사 버튼 클릭(새로 추가), 스페이스, Esc(전원 끄기)

**부품 툴팁과 목록(64개).** 빌드된 HTML의 `data-name` 항목 349개를 모두 정확히 한 번씩 덮도록 선택자를 짰습니다(스크립트로 대조, 빠짐 0, 겹침 0). 여기에 런타임 층(동전 받침, 반환 버튼, 날아가는 동전, 금고 속 동전, 화면)을 더했습니다. 설명의 숫자(가속도, 미터 값, 닫힌 스위치, 화면 상태 등)는 현재 모델 값입니다. 강조는 kit 기본(tone)입니다.

**단계 가이드(7단계).** 동전을 넣습니다 → 경사로를 굴러 내려갑니다(⅒배, 섬광, 확대) → 와이어를 밀어 펄스를 만듭니다 → 금고로 떨어집니다 → 릴레이가 전원을 붙잡습니다(신호 흐름) → 브라운관 예열과 자체 시험(시험 화면 고정) → 누운 화면과 조이스틱(스틱 → 유지). 단계마다 장면을 처음부터 다시 재생합니다.

**탐구 질문(3개).** 그림이 두 조건에서 동전을 실제로 굴려 확인합니다.

## 3. 모델과 숫자

- 1단위 = 5 mm, `GRAV` = 1962단위/s² = 9.81 m/s². 동전 지름 24.26 mm.
- 구름 a = g·sinθ ÷ (1 + β), 원판 β = ½, 미끄러짐 β = 0. L = 21.36 cm(메커 출구 → 경사로 끝).
- 기본값: a = 3.27 m/s², t = 0.361 s, v = 1.18 m/s, 낙하 0.168 s(정지 낙하 0.220 s), 수평 17.16 cm.
- **"27 cm 낙하" 바로잡음**: 27 cm는 메커 아래면에서 금고 윗면까지의 높이입니다. 동전 중심이 실제로 떨어지는 높이는 경사로 끝에서 23.70 cm이며, 캡션에 두 값을 기준과 함께 적었습니다.
- 캐비닛 높이는 모델(윗판 위 z = 358단위)로 약 179 cm입니다. 원본 문구의 178 cm 대신 모델 값을 썼습니다.
- 각주에 단순화 가정(원판, 공기 저항 무시, 낙하 중 수평 위치 보간, 벽 충돌 뒤 움직임 생략, 메커·전원 순서는 원본 연출 값)을 밝혔습니다.

## 5. 남은 문제

- **다크 테마 강조가 어둡습니다.** tone 강조에서 흐린 부품이 거의 배경색이 되어, 미터처럼 작은 강조 부품이 눈에 덜 띕니다(kit 공통 사항).
- **경사로 위 동전은 확대하지 않으면 여전히 작습니다.** 단계 2~4와 질문 1·2는 확대를 켜고 시작합니다.
- **조이스틱 끌기는 매우 민감합니다.** 실제 공의 이동이 몇 픽셀뿐이라 조금만 끌어도 최대 기울기가 됩니다. 방향은 포인터를 따릅니다. 등각 투영이라 화면의 오른쪽은 월드 좌표에서 오른쪽과 앞쪽이 섞이므로, 화면 오른쪽으로 끌면 스위치 두 개가 같이 닫힐 수 있습니다.
- **금고 속 동전**은 원본처럼 금고 앞벽에 가려 잘 보이지 않습니다.
- **캡처 뒤 kit 갱신**: 마지막 캡처 뒤 다른 에이전트가 `edu/kit`을 갱신해 HTML을 다시 빌드했습니다. 콘솔과 흐름 검사는 다시 통과했지만 캡처는 바로 앞 kit으로 찍은 것입니다.
- 1단계 보고서의 "헤드리스 프레임 지연"은 그대로입니다. 측정 시간 옆에 프레임 간격을 함께 보여 주어 오차를 드러냈습니다.
