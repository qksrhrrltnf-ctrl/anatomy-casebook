결과물: `spot-plate-ko.html`(다크), `spot-plate-ko-light.html`(라이트), `shots/ko-*.png`
설계: `C:\anatomy-work\edu-prep\spot-plate\설계.md`

## 1. 무엇을 만들었는가

React 예제 "반점판"(Fig 7)에 공통 교육 레이어(edu-kit)를 붙인 한국어 교육판입니다. 두 방울이 "간격 < merge"일 때 하나가 되는 문턱값을 다룹니다. 이 합쳐짐이 물리 계산이 아니라 그래픽 기법(거리장과 부드러운 합집합)이라는 점을 머리말, 꼬리말, 패널 소개, 공식 주석, 단계 8, 질문 4에 밝혔습니다.

| 기능 | 내용 |
|---|---|
| 한국어 카드 | 제목·힌트·판독값(`merge … px · 6쌍 중 …쌍 합쳐짐`)·범례·캡션. 캡션 끝 문장은 지금 merge 값을 따라 바뀝니다. |
| 변수 패널 | merge(0~48 px) 슬라이더, "살펴볼 쌍" 선택(4·10·16·24·32·44 px, 고르면 그 쌍을 강조). |
| 공식 5줄 | 합쳐지는 조건, 늘어나는 구간(보이는 간격 2√(merge × (간격 − merge))), 영향 없는 쌍, 고른 쌍의 상태(목 너비·보이는 간격), 펼쳐진 날 수. 모두 그림의 식(`rig.ts`의 `seenGapOf`, `neckOf`, `joinedAt`)에서 계산합니다. |
| 간격 수직선(그림 밖) | 0~48 px 위에 여섯 간격, 합쳐짐·늘어남·영향 없음 구간, 2 × merge 표시. 손잡이를 끌면 merge가 바뀌고, 점에 마우스를 올리면 그 쌍의 상태를 읽습니다. |
| 직접 조작 | 부채(날·각도기·피벗·멈춤 핀)에서 누른 채 좌우로 끌면 merge가 바뀝니다. 화살표, PageUp/PageDown, Home/End도 됩니다. 원본의 "마우스를 올리기만 해도 merge가 바뀜"과 "벗어나면 20으로 복귀"는 껐습니다(툴팁과 충돌). |
| 부품 툴팁·목록 | 19개 부품. 방울 쌍 6개는 지금 merge에서의 상태(합쳐짐/맞닿음/늘어남/영향 없음)를 툴팁에 보여 줍니다. |
| 단계 가이드 | 8단계: 방울 쌍 → 거리장 → merge를 키우면 → 문턱(24 px에서 맞닿음) → 문턱을 넘으면(25 px) → 늘어나는 구간 → 필러 게이지 부채 → 실제 물방울과 다른 점(표면장력). |
| 탐구 질문 | 4개: merge 33에서 몇 쌍(5쌍), 간격 24 px 쌍의 최소 merge(25 px), merge 32에서 간격 44 쌍(늘어남, 39.2 px), 실제 물방울이 합쳐지는 까닭(표면장력). |

## 4. 남은 문제

- **선 끝 검사.** merge 20에서 원본과 교육판 모두 떠 있는 끝이 있습니다(원본 15 / 590개). 방울의 반짝임(`ml-shine`), 날 위의 새김선(`ml-blade-line`), 프레임의 짧은 선처럼 원본 그림의 장식선이며, 교육판이 새로 만든 것은 없습니다. 개수는 merge에 따라 달라집니다(교육판 merge 1에서 8개). 그림 기하는 고치지 않았습니다. 0으로 맞출지는 결정이 필요합니다.
- 자동 투어 중에는 슬라이더·수직선·공식이 투어의 목표값(48 → 0 → 20)을 먼저 보여 주고, 그림은 그 값으로 천천히 따라갑니다.
- 390px에서는 원본 CSS가 그림을 130%로 키우고 넘친 부분을 잘라 부채가 가장자리에 가깝습니다. 휴대폰에서는 수직선의 손잡이 끌기가 더 편합니다.
- 2D 간격 실험 창은 지시대로 만들지 않았습니다.
