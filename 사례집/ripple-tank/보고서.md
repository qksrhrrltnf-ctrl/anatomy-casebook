## 2. 무엇을 설명하는 그림인가

학교 과학실의 **물결통(ripple tank)** 실물입니다(README, SKILL.md). 네 다리 위의 유리 수조, 그 위를 가로지르는 브리지와 진동 막대, 막대에 달린 두 개의 접촉구(dipper), 위쪽 팔에 달린 램프, 수조 아래 종이 스크린, 왼쪽의 진동수 조절 상자로 이루어져 있습니다. 시점은 44° 위에서 내려다봅니다.

그림 설명문(figcaption)과 `model.mjs`에 따르면 다음 물리를 실제로 계산합니다.

- 두 접촉구가 같은 위상으로 깊이 6 mm 물을 두드립니다. 램프는 접촉구보다 초당 0.75회 느리게 깜박이는 스트로보이므로, 물결이 0.75 Hz로 천천히 퍼지는 것처럼 보입니다("정직한 슬로 모션").
- 분산 관계 ω² = (gk + σk³/ρ) tanh kh(중력 + 표면장력)로 파장을 구합니다. 16 Hz에서 파장 1.45 cm, 마루 속도 23 cm/s입니다.
- 두 파원에서의 경로차가 반파장인 곳에서 상쇄되므로 마디선(nodal line)은 2⌊d/λ + ½⌋개입니다(5 cm 간격에서 6개). 판독값에 이 개수가 실시간으로 나옵니다.
- 물결 마루가 약한 렌즈가 되어 아래 종이에 밝은 선(커스틱)을 맺습니다. 종이 그림자는 실물의 1.53배입니다.
- 수조 벽 안쪽의 경사진 폼 해변이 반사파를 흡수합니다. 감쇠는 맑은 물의 점성만 넣었으므로 실제 수조보다 물결이 멀리 갑니다(설명문에 명시).

## 3. 조작법

`live.js` 기준입니다.

| 입력 | 동작 |
|---|---|
| 마우스를 가로로 이동 | 진동수 f (8~28 Hz) |
| 마우스를 세로로 이동 | 접촉구 간격 d (20~80 mm) |
| 클릭/탭 | 그 위치의 f, d로 설정. 터치에서는 가로로 끌면 f만 바뀝니다. |
| ← / → | f를 0.5 Hz씩(Shift는 2 Hz) |
| ↑ / ↓ | d를 2 mm씩(Shift는 10 mm) |
| Home / End | f를 최소 8 Hz / 최대 28 Hz로 |
| 자동 투어 | 처음 열면 f와 d가 사인 곡선으로 천천히 바뀝니다. 조작하면 멈추고, 3.6초 동안 입력이 없으면 다시 시작합니다. |
| 움직임 줄이기(`prefers-reduced-motion`) | 투어와 물결 진행이 멈추고 f 16 Hz, d 5.0 cm의 정지 화면이 됩니다(`shots/*-reduced.png`). |

## 4. 눈여겨볼 기법

- **SVG + WebGL 2겹.** 뒤 SVG → 종이 캔버스(`.rt-paper-gl`: 램프 빛, 커스틱, 다리·브리지·모터·상자 그림자, 굴절) → 가운데 SVG(다리, 수조) → 물 캔버스(`.rt-water-gl`: 반사, 유리) → 앞 SVG 순으로 쌓습니다. 셰이더가 SVG와 같은 등각 카메라(`glCamera`)와 같은 치수(`DATA`)를 써서 그림 속에 들어앉습니다(`references/webgl.md` "Worked case: the ripple tank").
- **순수 모델 분리.** `model.mjs`가 분산 관계, 마디선 개수, 배율, 커스틱 초점 위치를 계산하고, 빌드(설명문 수치)와 실행(판독값, 셰이더 uniform)이 같은 함수를 씁니다.
- **변화가 매질을 타고 퍼짐.** 진동수를 바꾸면 전체 무늬가 한꺼번에 바뀌지 않습니다. 50 ms 간격 32개 표본의 이력(위상, ω, k, 감쇠, 군속도)을 32×2 텍스처로 올리고, 각 점이 자기 거리/군속도만큼 과거 값을 읽습니다. 그래서 새 파장이 접촉구에서 바깥으로 번져 나갑니다(`references/webgl.md` 234~235행). `shots/*-freq-8hz*.png`, `*-freq-28hz*.png`에서 파장이 바뀐 모습을 볼 수 있습니다.
- **WebGL 없는 대체 화면.** WebGL이 없으면 `model.mjs`의 `patternOf`가 그린 마루 원호와 마디 쌍곡선을 SVG 선으로 보여 줍니다(`shots/*-no-webgl.png`). 물리 내용은 그대로 읽힙니다.
- **테마별 잉크.** 다크에서는 빛만 더하는 종이 캔버스를 screen 혼합하고, 물 캔버스는 어둡게도 해야 하므로 일반 혼합을 유지합니다(SKILL.md). 라이트에서는 첫 점등 때 화면이 밝아지기만 하도록 처리했습니다.
- **고주파 모아레 방지.** 투영된 파장이 2.5~5 장치 픽셀보다 짧아지면 그 성분을 줄여 28 Hz에서도 모아레가 생기지 않게 합니다.
- **2단계 참고점:** 물리 모델을 `model.mjs` 하나에 두고 설명문·판독값·셰이더가 같은 수식을 쓰는 구조, 그리고 "WebGL이 꺼져도 SVG만으로 개념이 읽히게" 만드는 원칙은 전공 실험 장치 그림에 그대로 옮길 수 있습니다. lathe(`kit/lathe.mjs`)와 tube(`kit/tube.mjs`, 모터 케이블)도 쓰였습니다. 분해·인쇄(`sheet.mjs`) 기능은 이 예제에 없습니다.

## 5. 교육 활용 메모

- 중학교 과학 "파동"과 고등학교 물리학 "파동의 간섭·굴절" 단원에 바로 쓸 수 있습니다. 실제 물결통 실험을 하기 전 장치 구조(램프, 수조, 스크린)를 설명하고, 진동수를 바꾸면 파장이 짧아지고 마디선이 늘어나는 관계를 판독값으로 확인하게 할 수 있습니다.
- 접촉구 간격 d와 파장 λ로 마디선 수 2⌊d/λ + ½⌋를 예측한 뒤 그림으로 확인하는 탐구 활동, 그리고 물결이 렌즈처럼 빛을 모아 밝은 무늬를 만드는 원리(굴절) 설명에 적합합니다.

## 6. 문제와 미해결 사항

- 재현 결과에는 문제가 없습니다(바이트 일치, 선 검사 통과, 콘솔 깨끗함).
- 캡처 관련 참고: 키 입력(`--key Home`/`End`)으로 찍은 장면에는 캔버스가 포커스를 받아 생긴 안쪽 테두리(포커스 표시)가 보입니다. 정상 동작입니다.
- 진동수 변경 캡처는 목표값(8, 28 Hz)에 다가가는 도중에 찍혔고, 키 입력 3.6초 뒤 자동 투어가 다시 시작되므로 `+3000ms` 장면은 투어 쪽으로 되돌아가는 값(예: 9.0 Hz, 22.3 Hz)입니다. 목표값에 가장 가까운 장면은 `*-1500.png`(8.5 Hz, 27.0 Hz 부근)입니다.
- capture.mjs가 터미널에 출력하는 판독값은 마지막 촬영 시점 값이라, 첫 장 이미지 안의 판독값과 조금 다를 수 있습니다.
- 작업 환경은 Node 24이고 원저자 CI는 Node 22입니다. 이 예제는 그래도 바이트가 같았습니다.
