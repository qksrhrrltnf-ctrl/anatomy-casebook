## 2. 넣은 것

**한국어 카드.** 모서리 글자(그림 3 · 물결통 · 조작 안내 · 판독값), 범례 3개, 설명문을 한국어로 바꾸었습니다. 판독값 예: `f 16.0 Hz · λ 1.45 cm · d 5.0 cm · 마디선 6개`, 파원이 1개일 때 `f 16.0 Hz · λ 1.45 cm · 파원 1개`. 설명문은 템플릿이라 진동수, 파장, 속력, 간격, 마디선 수, 수심이 지금 모델 값으로 바뀝니다. 램프 높이(40.0 cm), 종이까지의 거리(21.2 cm), 배율(1.53)은 빌드 때 그림 기하에서 계산해 넣습니다. 화면 낭독(aria-live)과 무대 설명도 한국어입니다.

**변수 패널(실험 탭).**
- 진동수 f: 8~28 Hz, 0.5 Hz 간격(모델의 `RANGE`)
- 파원 간격 d: 2.0~8.0 cm, 0.1 cm 간격
- 수심 h: 3~8 mm, 0.5 mm 간격. 그림 속 물 높이는 그대로 두고 계산에 쓰는 수심만 바꿉니다(도움말과 각주에 밝힘). 이 범위를 벗어나면 셰이더 이력 텍스처의 양자화 범위를 넘으므로 막았습니다.
- 파원 수: 1개 / 2개. 1개로 하면 앞 접촉구가 물 위로 5 들리고, 셰이더의 두 번째 파원 가중치(`uW2`)가 0.35 s 감쇠 스프링으로 0이 됩니다. SVG 대체 화면도 파원 하나의 원호만 그립니다.
- 예측 마디선 겹쳐 보기: 공식 2⌊d/λ + ½⌋로 계산한 마디 쌍곡선을 종이 위(램프 투영 1.53배)에 파란 점선으로 겹칩니다. 실제 무늬의 회색 띠와 겹치는 것을 볼 수 있습니다(`ko-guide-zoom-*.png`).
- 물결 멈춰 보기: 스트로보 깜박임을 진동수에 맞춰(겉보기 진동수 0.75 → 0 Hz) 무늬가 멈춘 것처럼 보입니다.
- 자동 재생(키트 표준): 처음에는 원본 투어(f와 d가 천천히 바뀜)가 돌고, 그림이나 패널을 건드리면 꺼진 뒤 다시 켜지지 않습니다.
- 공식 표시: 파장 λ = v ÷ f, 분산 관계와 수심, 마디선 수 N = 2⌊d/λ + ½⌋(d/λ + ½은 반올림하지 않고 버림으로 표시해 ⌊ ⌋ 결과와 어긋나지 않게 함), 종이 위 파장, 겉보기 진동수.

**직접 조작.**
- 수조 위를 누른 채 끌기: 가로 진동수, 세로 간격(원본의 마우스 올림 조작을 끌기로 바꾸어 툴팁과 분리). 터치에서는 가로로 끌어 진동수.
- 접촉구 끌기: 접촉구 근처(14 px)를 누르고 끌면 막대 방향으로 간격이 바뀝니다.
- 키보드: ←→ 진동수, ↑↓ 간격, Shift 크게, Home/End 진동수 최소·최대(원본과 같음). 그림 쪽에서 바꾼 값은 `edu.sync`로 패널 슬라이더에 반영됩니다.

**부품 툴팁과 목록(23개).** 파원 A·B, 진동 막대, 편심 바퀴, 진동 모터, 코일 스프링, 브리지, 물, 경사 해변, 유리 바닥 수조, 다리와 수평 나사, 스트로보 램프, 램프 기둥과 팔, 종이 스크린, 마디선(예측), 진동수 손잡이, 진동수 계기, 전원 스위치와 표시등, 조절 상자, 전선, 눈금자, 받침판, 이름판. 원본에 선택자가 없던 부품은 교육판 빌드에서 `<g data-part>`로 묶었습니다(기하는 그대로). 그림 층 3장(뒤·가운데·앞 SVG)과 `pointer-events:none` 층은 키트의 `root`(모든 svg)와 `probe`로 처리했습니다.

**단계 가이드(7단계).** 물결 만들기(파원 1개) → 빛으로 물결 보기 → 진동수와 파장(24 Hz) → 수심과 파장(8 Hz, 3 mm, 굴절 설명) → 두 파원의 간섭 → 마디선(예측선 켬) → 간격을 넓히면(7 cm).

**탐구 질문(3개).** 보기의 숫자도 `ko.mjs`가 모델로 계산합니다. d/λ + ½이 정수 경계에서 0.1 이상 떨어진 조합만 골랐습니다.
1. 20 Hz에서 간격 4 → 8 cm: 마디선 6개 → 14개(2배가 아님)
2. 5 cm에서 진동수 8 → 24 Hz: 4개 → 10개(파장은 2.87 → 1.03 cm, 3배만큼 짧아지지 않음)
3. 8 Hz, 6.5 cm에서 수심 6 → 3 mm: 4개 → 6개(속력 22.9 → 19.3 cm/s, 파장 2.87 → 2.41 cm)

## 3. 조작법

| 무엇을 | 어떻게 |
|---|---|
| 진동수·간격 바꾸기 | 수조 위를 누른 채 끌기, 접촉구 끌기, 화살표 키, 또는 실험 탭 슬라이더 |
| 수심·파원 수·예측선·멈춰 보기 | 실험 탭 |
| 부품 알아보기 | 그림 위에 마우스 올리기(휴대폰은 탭), 또는 부품 탭 목록 |
| 원리 따라가기 | 단계 탭의 이전/다음 |
| 예측하기 | 질문 탭에서 답 고르기 → 그림이 바뀌며 확인(2.2초) |

## 4. 모델과 단순화

- 분산 관계 ω² = (gk + σk³/ρ) tanh kh(원본 `model.mjs` 그대로)로 k를 구하고, 파장·속력·감쇠·마디선 수를 계산합니다. 교육판은 `stateAt(f, d, h)`(수심을 잠시 바꿔 계산하고 되돌림)와 패널 값 표(`valuesOf`)만 더했습니다.
- 수심 효과는 진동수가 낮을 때만 큽니다. 8 Hz에서는 6 → 3 mm로 파장이 2.87 → 2.41 cm가 되지만 28 Hz에서는 0.91 → 0.90 cm입니다. 단계 4에서 이를 설명합니다.
- 파원을 1개로 바꾸면 두 번째 물결이 수조 전체에서 함께 약해집니다(실제로는 마지막 물결이 퍼져 나가며 사라집니다). 각주에 밝혔습니다.
- 예측 마디선은 값이 다 바뀐 뒤의 위치입니다. 값을 바꾼 직후 1~2초는 새 물결이 퍼지는 동안 무늬와 어긋납니다(도움말에 밝힘).

## 6. 남은 문제

- 진동수·간격은 원본처럼 감쇠 스프링(0.6 s, 0.4 s)으로 천천히 다가가므로, 슬라이더를 끝까지 옮기면 판독값이 목표에 닿는 데 3~4초 걸립니다. 패널 공식과 질문 해설은 멈춘 뒤의 값을 바로 보여 줍니다.
- 다크 테마에서 부품을 강조하면 키트 표준(tone) 방식이라 그림 전체가 어두워지고, WebGL 빛(커스틱, 물 반사)은 흐려지지 않습니다.
- 휴대폰에서는 접촉구가 작아(지름 약 5) 끌기가 어렵습니다. 간격은 슬라이더로도 바꿀 수 있습니다.
