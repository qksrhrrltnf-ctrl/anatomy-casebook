## 2. 넣은 것

**조작 방식 변경(결정 사항).**
- 전원은 로커 스위치와 표시등을 누를 때, Esc 키를 누를 때, 패널의 전원 스위치를 쓸 때만 바뀝니다. 본체를 눌러도 전원이 바뀌지 않으므로, 본체를 눌러 툴팁을 볼 수 있습니다.
- 그림 속 키 클릭과 키보드 타자는 원본과 같습니다.
- 한글 입력이 들어오면 상태 줄에서 영문 자판으로 바꾸라고 안내합니다.

**변수 패널(실험 탭).**
- 전원: 켬/끔. 로커, 표시등, Esc, 자동 재생이 전원을 바꾸면 이 스위치도 따라갑니다.
- 화면 꺼짐·켜짐 느리게 보기: 1~10배. 원본 연출 시간(꺼질 때 0.1 s, 0.16 s, 0.5 s / 켜질 때 0.14 s, 0.22 s)에 배율을 곱합니다. 이 시간들은 상수 표 하나에서 나와 그림, 공식, 캡션, 각주에 똑같이 쓰입니다.
- 판독값 글자 표시: 글자 / 10진 코드 / 2진 코드. 예: `켜짐 · 9자 · ! = 00100001`
- 신호 흐름 보기: 글자를 칠 때마다 키보드 → 케이블 → 포트 → 본체 → 화면을 차례로 강조합니다(`edu.sequence`, 단계당 180 ms × 배율).
- 자동 재생: kit 표준 정책을 따릅니다. 원본의 9초 재개 타이머는 지웠습니다.
- 공식:
  - 문자 코드: `'x' → 120 → 01111000`
  - 한 줄의 기억 공간: `10자 × 1바이트 = 10바이트 = 80비트 (최대 20자)`
  - 꺼질 때·켜질 때의 단계 시간(배율 반영)

**상태 줄.**
- 전원이 꺼진 채 타자하면 입력되지 않는다고 알립니다.
- 20자가 차면 줄이 가득 찼다고 알립니다.
- 한글 입력이 들어오면 경고합니다.

**동작 줄이기.**
- 자동 재생은 꺼져 있습니다.
- Esc로 끄면 원본처럼 즉시 꺼집니다.
- 학생이 느리게 보기를 2배 이상으로 고르면, 동작 줄이기 설정에서도 꺼짐 장면을 재생합니다.
- 신호 흐름은 차례 없이 한 번에 0.9초 강조합니다.

**카드.** 제목, 조작 안내(`누르고 영문 타자 · Esc는 전원`), 판독값(`켜짐 · 13자 · 마지막 키 e`, `꺼짐`), 범례, 캡션을 한국어로 바꾸었습니다. 캡션의 한 줄 최대 글자 수와 꺼짐 단계 시간, 범례의 키 개수는 템플릿이라 모델을 따릅니다. 예를 들어 느리게 보기 8배이면 캡션도 `0.8 s … 1.28 s … 4 s`가 됩니다.

**부품 툴팁·목록(17종).** Shift 키, 키, 키보드, 코일 케이블, 키보드 포트, 입력한 글자와 커서, 로고, CRT 화면, 전원 표시등, 스피커 그릴, 플로피 디스크 드라이브, 전원 스위치, 통풍구, 손잡이 홈, 본체, 명판, 받침판

**단계 가이드(7단계).** 입력 장치(키보드) → 신호가 지나는 길(케이블과 포트) → 처리 장치(글자를 코드로, a → 97 → 01100001) → 주기억 장치(한 줄을 기억, "hello, claude" 13자 = 13바이트) → 출력 장치(화면과 스피커) → 보조 기억 장치(플로피) → 전원과 화면이 꺼지는 모습(6배 느리게)

**탐구 질문(3개).** 설계의 질문 4번(전원이 꺼진 채 키 누르기)은 결정 사항대로 뺐습니다.
1. 전원을 끄면 CRT 화면은 어떻게 사라질까? 정답: 가로 한 줄로 접혔다가 가운데 점이 되어 사라진다. 8배 느리게 확인합니다.
2. 대문자 A의 코드는? 정답 65. 해설에 `65(01000001)`과 `97(01100001)`을 모델에서 계산해 넣습니다.
3. 20자가 찬 줄에 한 글자를 더 치면? 정답: 키는 내려가지만 화면에는 더 찍히지 않는다

## 3. 모델

- 문자 코드는 브라우저의 `charCodeAt`(ASCII) 값입니다. 1글자 = 1바이트 = 8비트입니다.
- 한 줄 최대 20자, 키 눌림 깊이 2.2(원본 `MAX_CHARS`, `DOWN`)
- CRT 시간표는 원본 `crtFrame()`의 숫자를 상수 표 `CRT_T`로 옮긴 것입니다. 실행 중에는 `powerClock += dt / 배율`로 진행합니다.
- 전원이 꺼지면 키도 내려가지 않습니다. 원본 모델 그대로이며, 실제 키보드와 다르다는 점을 각주에 밝혔습니다.

## 5. 남은 문제와 알릴 점

- **원본의 선 끝 문제 하나를 교육판에서 표시만 바꾸었습니다.** 원본도 전원을 끈 상태에서는 CRT 유리의 반사 곡선 양 끝이 떠 있다고 나옵니다(`2 of 82 ends float`). 켜진 상태에서는 주사선이 끝을 받쳐 주어 0입니다. 교육판은 꺼진 자세(단계 7, 질문 1)를 오래 보여 주므로, 이 반사 곡선에 `data-free`(의도한 열린 끝)를 달았습니다. 그래서 검사 대상이 82개에서 80개로 줄었고, 두 상태 모두 0입니다. 원본(`examples/`)은 고치지 않았습니다.
- 신호 흐름 강조는 단계당 180 ms로 빠릅니다. 느리게 보기 배율을 올리면 같이 느려집니다. 다크 테마에서는 강조 대비가 약한 편입니다(kit 공통 사항).
- 그림을 클릭하기만 하면 자동 재생이 꺼지지 않습니다(초점만 줌). 타자, 키 클릭, 로커·표시등 클릭, 패널 조작에서 꺼집니다.
- 투어 문장("hello, claude" 등)과 화면 글자는 영문입니다. 자판에 한글 키가 없기 때문입니다.
- 휴대폰에서 키 58개는 작아서 손가락으로 누르기 어렵습니다(원본과 같음). 휴대폰 화면 키보드로 타자하는 것은 시험하지 않았습니다.
